# 90后未婚规模的口径学：『1.7亿人里1亿未婚』的真伪分层与挪用链

## 0. 分析对象限定 (Scope Restriction)

本条目遵循本库铁律：分析对象是**言论与统计数据文本**，不是**人类**。不评价"不结婚的人"，不产出任何关于未婚群体的画像断言（规约见 [`RUBRIC.md`](../../skills/source-evaluator/RUBRIC.md)）。本条目也不裁决"该不该结婚"——它固定的是**数字的口径边界**与**说法的挪用链**。

---

## 1. 核心结论：一个数字的两半命运

"**1.7亿90后，约1亿未婚**"这一说法需要拆成两半判定：

| 成分 | 判定 | 依据 |
| :--- | :--- | :--- |
| **"约1亿未婚"（时点状态）** | **数量级成立** | 七普90后1.782亿 × 2020年未婚率57.8% ≈ **1.03亿**；2024年末抽样推算90后约1.76亿，非婚状态估算约9500万-1亿（媒体推算口径） |
| **"1.7亿"（分母）** | **口径陈旧但非捏造** | 七普实测1.78亿；"1.7亿"出自六普前旧资料口径（福建辟谣平台2021年文即用1.7亿），后被沿用 |
| **由"1亿未婚"推出的任何结论** | **全部另议** | "未婚"是**时点状态**（初婚推迟的可逆中间态），不是"不婚"（意愿）、不是"绝育绝户"（终局断言）。挪用发生在这一步 |

**关键口径区分**（本条目的核心知识点）：

```
未婚（时点状态，登记/事实婚姻口径） ≠ 单身（含离异丧偶及独居状态）
        ≠ 不婚主义（观念意愿） ≠ 适婚未婚（年龄限定）
```

官方从未发布过"90后结婚率"或"90后1亿人不结婚"的任何统计——**唯一官方可比数字**是：七普90后1.78亿、年鉴口径2020年未婚率57.8%、2020年平均初婚年龄28.67岁、2024年结婚登记610.6万对。

---

## 2. 时间线与数据基底

- **初婚年龄**：2010年24.89岁 → 2020年28.67岁（七普长表），十年推迟3.78岁；上海2024年30.1岁、安徽2021年男31.89/女30.73（地方民政口径）。
- **未婚率**（事实婚姻口径，含未婚同居）：30岁未婚率2013年14.56% → 2023年29.97%，翻倍；35岁降至11.19%——**这11.19%是"推迟"与"终身不婚"的分界证据**：绝大多数未婚是延迟，不是放弃。
- **结婚登记**：2013年1346.9万对（峰值）→ 2024年610.6万对；2023年曾回升12.4%（疫情后补偿），2024年再降20.5%。初婚人数2013年2385.96万 → 2022年1051.76万。
- **性别结构**：2023年30岁未婚率男38.87%/女20.16%——男性未婚率接近女性两倍，"农村剩男×城市剩女"的空间错配是真实结构（90后性别比约110）。

## 3. 挪用链（可溯源节点）

本说法的**数字层大致为真**，但其传播生命力于挪用：

1. **2021-08 原形**："1.7亿90后仅1000万对结婚，结婚率不足10%"——福建辟谣平台2021-08-26证伪：民政部无此数据；仅2018-2019两年20-29岁登记已超2000万人。**此版本数字为假**。
2. **修正形**："90后约1亿未婚"——与官方口径推算值（1.03亿）重合，**数字层成立**，但来源常仍标注"民政部门统计"（伪造归因）。
3. **口径滑移**：未婚→单身→独居（混入"空巢青年9200万"，原始调查主体不明）→"不婚不育"（2024-08《上亿青年为何不婚不育，甘愿绝户？》，"绝户"为终局断言，无任何数据支撑）。
4. **叙事接驳**：接入生育率叙事（"婚都不想结还生什么孩子"，2024-11）与民族危机叙事；境外报道将其与"强制社保"并置入"全民降薪"框架。
5. **同族算法错误**："80后死亡率超70后"（2025-02）、"90后存活率仅85%"（2026）——与"结婚率不足10%"同属**两套抽样系统相减**的错误算法家族（腾讯较真2026-09-03）。

## 4. 结构拆解与判据

### 4.1 为什么"真数字"比"假数字"更值得警惕
假数字（1000万对）会被辟谣击穿；**真数字（1亿未婚）+ 伪造归因（"民政部门统计"）+ 口径滑移（未婚→不婚→绝户）**的组合无法被简单辟谣——辟谣者必须承认数字本身，只能纠正口径，而口径纠正的传播力远弱于数字本身。这是本库 [`availability-heuristic`](../cognitive-bias/availability-heuristic.md) 的升级案例：**可得性锚点由假象升级为真值**，但锚点之后的推断链（时点状态→终局断言）仍是偷换。

### 4.2 判据
- **口径检验**：凡引用"90后1亿未婚"的言论，先问三件事——分母口径（七普1.78亿还是六普前1.7亿）？未婚定义（时点还是终身）？年龄限定（全队列还是适婚段）？三者答不出的，标记 `FLAG_STATISTICAL_SCOPE_SLIP`（统计口径滑移）；
- **时点/终局检验**：凡从时点未婚率推出"不婚不育/绝户/断代"终局结论的，要求其解释35岁未婚率降至11.19%这一反证；无法解释的，按不可证伪处理；
- **归因检验**：凡标注"民政部门统计/官方统计"但查无官方口径的（官方只发布登记总对数及年龄分布），标记 `FLAG_RUMOR_RETOLD`（伪造归因）。

### 4.3 与相邻概念的分工
- 挪用链的"民族危机/生育率崩塌"接驳归 [`macro-entity-parasitic-projection`](../cognitive-bias/macro-entity-parasitic-projection.md) 处置（言论层）；
- "什么年龄该结婚"的规训话语归 [`social-clock-phenomenology`](./social-clock-phenomenology.md)；
- 本条目只管**数字的口径学与挪用链结构**。

## 5. 未核实项与待证 (Open Questions)

1. **2025年全年结婚登记数**未发布（截至2026-10，仅Q1的181万对）；
2. **"空巢青年9200万"的原始调查机构**不明（所有转引均称"据统计"）；
3. **七普长表90后未婚人口精确单值**：1.03亿为57.8%×1.78亿的推算，官方未直接发布该单值；
4. **"民族危机"接驳的最早标志性爆文**：变形方向已证实，具体节点未溯源（抽样中最接近的是2024-08"绝户"文）；
5. **可证伪命题**：随初婚年龄推迟趋稳，"90后1亿未婚"话题的挪用方向是否从"道德规训"（自私/躺平）转向"制度归因"（社保/房产/教育成本）——2026年检索样本已显示此转向迹象（"理性经济计算"类标题2026年增多），可继续观测。
