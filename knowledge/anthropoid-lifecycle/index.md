# 领域总览：人猿生命周期控制 (Anthropoid Lifecycle Control)

## 1. 领域范围与背景说明

“人猿生命周期控制”（Anthropoid Lifecycle Control，学术语境又称**年龄阶段宿命论 / 强制性时间规范规训，Coercive Chrononormativity**），指控制主体以“什么年龄做什么事”（"doing what fits one's age"）为道义或规制借口，对被控制对象强行施加线性同步管道锁定，从而剥夺其探索方差、回溯成本与自主决策权的系统性控制行为。

本领域知识库从**控制论（Cybernetics）**、**运筹学（Operations Research）**、**社会学（Sociology）**以及**认知神经科学（Cognitive Neuroscience）**四个硬学科视角，彻底拆解该行为的生成机理、控制成本数学本质、社会现实表征与科学替代模型。
