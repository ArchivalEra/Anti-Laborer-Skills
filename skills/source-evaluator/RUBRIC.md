# 内容分辨与信噪比评定细则 (Evaluation Rubric)

[English Version](./RUBRIC.en.md) | [中文版本](./RUBRIC.md)

---

本细则为 `source-evaluator` 技能的渐进披露参考规约，界定 L1/L2/L3 三级分流准则、典型谬误表征及高信噪比实证特征。

---

## 一、分层过滤架构 (The 3-Tier Sieve)

```
[原始输入文本 / 检索流]
        │
        ▼
[L1 快速硬拦截 (Hard-Cut)] ──(命中政治键政/情绪谩骂)──► [直接丢弃 / 零推理开销]
        │ (通过)
        ▼
[L2 信噪比门禁 (SNR Gate)] ──(纯主观宣泄 / 零事实基础)──► [判定淘汰]
        │ (通过)
        ▼
[L3 实证解构抽取 (Audit)] ──► [输出 ExtractionCard 提炼卡片]
```

---

## 二、L1 快速硬拦截标准 (一票否决)

凡命中文本具备以下任一特征，**不作任何辩驳，直接判定淘汰 (REJECT_L1)**：

1. **立场站队与派系贴标签**：
   - 带有强烈意识形态派系词汇（如“公知”、“粉红”、“神友”、“兔友”、“殖人”、“润人”等对立标签）。
   - 企图将技术、工程或科学议题强行拉入地缘政治立场站队。
2. **纯情绪宣泄与人身攻击**：
   - 包含密集侮辱性词汇、粗口谩骂、诅咒或虚无主义发泄。
   - 使用连续 3 个以上的攻击性标点（如 `！！！`、`？？？`）。
3. **恶意煽动与阴谋论叙事**：
   - 缺乏基本事实锚点的宏大叙事构陷与动机论（“肯定收钱了”、“境外势力全盘操控”等）。

## 三、力工思维特征库 (Laborer Mentality Taxonomies)

“力工思维”（Laborer Mentality）指在知识工作与工程领域中，以机械能耗替代系统设计、以认知惰性否定智力价值的反智倾向。常见表征包括：

| 谬误类型 | 核心主张 | 科学解构锚点 |
| :--- | :--- | :--- |
| **手段目的倒置** | 崇拜疲惫与工时消耗，将“吃苦与受累”本身等同于价值产出。 | 边际效用递减规律、系统能耗-产出比（Energy-Yield Ratio）。 |
| **反智与反抽象** | 否定算法、架构、数学与理论模型的杠杆作用，宣称“理论都是忽悠，只有硬干才是真的”。 | 复杂度理论（\(O(n)\) vs \(O(n^2)\)）、软件系统拓扑、抽象层级隔离。 |
| **排斥自动化杠杆** | 将自动化工具与脚本视作“偷奸耍滑”，抗拒生产力工具进化。 | 运筹学效率前沿（Pareto Efficiency）、工业化分工理论。 |
| **虚无主义经验论** | 拒绝控制变量与量化实证，用孤立的幸存者偏差经验对抗统计规律。 | 假设检验（Hypothesis Testing）、样本偏差、置信区间。 |
