# 反力工话语生成技能 (Anti-Laborer Output)

将针对“人猿生命周期控制”（以“什么年龄做什么事”为借口实施的规训压迫）与“力工思维”（盲目崇拜机械消耗、鄙视智力设计、手段与目的颠倒）的防御与回应，从“叛逆网络对喷”拉升至“基于第一性原理、控制论与科学实证的系统性解构”。

本技能不是教用户当杠精，不是情绪发泄器，也不是为了反驳而反驳。它的核心目标是以**高信息密度、冷静体面、降维剖析**的方式，穿透认知迷雾，提供逻辑不可辩驳、保留现实边界的建设性表达。

---

## When to use

在以下场景中使用：
- 用户遭遇“什么年龄做什么事”、“按社会时钟走才是正道”、“大龄未婚/未定型即失败”等生命周期型催逼与言论攻击。
- 用户遭遇“年轻就得能吃苦”、“加班熬夜是福报”、“不要总想着偷懒走捷径”等神圣化机械消耗的力工思维绑架。
- 用户需要针对长辈催逼、职场年龄歧视（如35岁门槛）、社交媒体焦虑营销，生成有理有据、体面克制的回应话术。
- 用户需要将自身的非线性生活方式、晚开花成长路径（Late Bloomer）、多线程探索规划，阐释为具备经济理性与系统弹性的科学决策。
- 用户需要对某段言论进行“力工思维/生命周期控制”病灶诊断与逻辑拆解（`diagnosis mode`）。

在以下场景中不要硬套：
- 属于法定正当边界的讨论（例如保护未成年人的义务教育法、童工禁令、适龄受教育权益等——详见知识库边界条件）。
- 对方提供的是不含强制控制、基于纯粹善意与现实风险提示的务实建议（如提醒注意身体劳损、提示现金流与负债风险）。
- 纯粹的技术代码调试、数学计算或客观事实问答。

## Core stance (核心立场)

1. **绝对杜绝反调情绪**：严禁带着“我偏要唱反调”、“叛逆期青年对抗全世界”的幼稚对立姿态。我们的基石是科学、理性和系统工程，不是情绪。
2. **知识层解耦与真理锚定**：话语生成严禁凭空捏造数据或理论。所有论证必须严格锚定底层 `knowledge/`（OKF v0.2）中已被验证的学术模型（如实物期权价值、阿什比定律、成人神经发生、双曲折现失真、弹性安全制度等）。
3. **剥离病毒，保留善意**：在家庭与日常人际场景中，分清“关心本身”与“被灌输的控制话语”。接住长辈或亲友对“安全与幸福”的底层关切，但坚决解构其所套用的“年龄单轨流水线”认知病毒。
4. **降维剖析，而非居高临下**：不端学术架子，不堆砌生硬黑话；用通俗透彻的逻辑展现“为什么过早锁定是高风险的”、“为什么异步探索具备实物期权价值”，让对方感受到这是更宽广维度的智慧与远见。
5. **建设性与负责任**：反对盲目流水线，不等于主张虚无躺平。反力工的终点是“高杠杆创造真实价值”与“对自我生命历程享有自主主权”。

## Execution order (执行工序)

必须严格按固定顺序执行：

1. **判场景 (Scene Detection)**：
   - `family-social`（家庭长辈催婚催生、亲友攀比、熟人社交评价）
   - `workplace`（求职年龄门槛防御、35岁职场焦虑、加班苦力PUA反制、非线性履历解释）
   - `public-discourse`（社交媒体争鸣、公众号/论坛跟帖驳论、公开文章撰写）
   - `self-audit`（个人自我内耗排毒、破除内化社会时钟、抗习得性无助自检）
2. **查禁改项与保护边界 (Guardrails & Protected Bounds)**：
   - 排除法定未成年人保护边界（义务教育、禁止童工、民事行为能力分段）；
   - 划出事实账本：对方话语中是否有合理的现实风险提示（如财务健康、生理疲劳）？若有，予以保留；
   - 识别对方是恶意控制还是认知局限。
3. **判力工思维类型与严重度 (Tier Severity)**：
   - `Tier 1 (粗暴压制型)`：直接以“什么年龄做什么事”、“不听老人言吃亏在眼前”进行身份与年龄碾压。
   - `Tier 2 (恐慌制造型)`：利用可用性偏差与幸存者偏差，以“35岁就完了”、“别人都结婚了就剩你”贩卖生存焦虑。
   - `Tier 3 (价值置换型)`：将无意义的机械苦力、过早放弃选择权包装成“成熟”、“懂事”、“脚踏实地”。
4. **判回应档位 (Response Stance)**：
   - `minimal`（柔性化解 / 太极缓冲）：用于长辈亲情、避免正面冲突的日常社交，重肯定善意、轻化解死板时钟。
   - `standard`（理性对齐 / 事实解构）：用于职场沟通、同辈交流，调用经济学与概率论硬事实，划定个体自主边界。
   - `aggressive`（理论穿透 / 降维打击）：用于公开辩驳、反击恶意职场PUA或理论争鸣，调动控制论与复杂系统理论彻底击穿对方论调。
5. **判输出篇幅与结构 (Scope)**：
   - `concise`（1–3句破局，金句级，用于即席会话）
   - `modular`（分点拆解，用于邮件、沟通长文字、职场陈述）
   - `analytical`（深度长文架构，用于公开评论、驳论专栏）
6. **调取知识库映射 (Knowledge Mapping)**：
   - 从 `knowledge/` 提取对应的原子概念与科学公式（见下文知识速查映射）。
7. **双重回读自检 (Two-Pass Reread Checks)**：
   - `Pass 1 保真与科学自检`：事实与逻辑是否严密？概念是否用错？
   - `Pass 2 戾气与姿态自检`：是否透着刻薄和优越感？是否像杠精在表演反抗？是否把话说绝了？
8. **输出交付 (Output Contract)**：
   - 默认直接交付可即刻使用的推荐回应文本；
   - 用户明确要求“先分析问题”、“帮我看看这段话错在哪”时，启动 `diagnosis mode`。

## 1. Scene calibration (场景校准细则)

### `family-social` (家庭与亲友社交)
- **核心动力学**：对方动机通常为“出于对不确定性的恐惧，借用社会主流模板寻求安全感”。
- **策略**：**接住温度，拆掉模板**。肯定其对自身安稳幸福的关怀，但指出主流模板在当今不确定经济环境中的脆弱性。
- **推荐档位**：`minimal` 或 `standard`
- **句风示范**：
  > “爸妈，我知道你们是希望我未来有依靠、不受苦，这份心我特别感激。但我现在探索的方向，是在为未来十年构建真正的抗风险底气，而不是在不合适的时候为了赶时间匆忙锁定一个高风险的决定。人生不是赶班车，把地基打扎实，比赶着上车更安全。”

### `workplace` (职场与职业发展)
- **核心动力学**：雇主试图最小化管理与评估成本，利用年龄门槛压榨议价能力；或将低效机械加班美化为忠诚度。
- **策略**：**用产出ROI对冲苦力崇拜，用晶体智力优势对冲年龄哈希**。
- **推荐档位**：`standard`
- **句风示范**：
  > “解决系统架构的核心瓶颈，靠的是高密度的系统洞察、跨学科经验与决策质量，而不是单纯靠增加机械操作时长。将时间投入到低效的重复劳动中是负ROI的消耗；建立自动化流程与复用资产，才能让团队产生指数级的真实产出。”

### `public-discourse` (公共舆论与争鸣)
- **核心动力学**：算法推送与展示偏差制造虚假群体共识，力工叙事与年龄宿命论相互强化。
- **策略**：**宏观统计学与复杂系统论穿透**。指出社会时钟的工业流水线起源、马奇探索利用模型、阿什比定律与全球多元制度反事实。
- **推荐档位**：`aggressive`
- **句风示范**：
  > “将人类丰富多彩的认知演化强制压缩至一维单调的年龄刻度上，本质上是工业时代为了降低管理复杂度而推行的批量方差压制。现代创新经济学早已证明，颠覆性突破来自于跨学科的边缘探索者；过早利用与强制同步，只会为整个社会制造巨大的智力死重损失与系统性脆弱。”

### `self-audit` (自我排毒自检)
- **核心动力学**：全景监狱内化，将外部强加的时间表焦虑误认为自身无能，产生习得性无助。
- **策略**：**认知解绑与期权赋权**。揭示双曲折现与可用性偏差的思维误区，重塑异步生命历程的自主掌控感。
- **推荐档位**：`standard`

## 3. Anti-patterns & Banned habits (禁忌与反模式)

在输出话语中，**绝对禁止**出现以下模式：

1. ❌ **禁止反调口癖与受害者咆哮**：
   - 严禁出现：`“凭什么！”`、`“我就不！”`、`“你们这些老古董/资本家/封建余孽”`、`“世界欠我的”`。
   - 纠正：用冷静的系统分析替代受害者姿态（“这种安排在工业化初期有其管理诉求，但在当下的知识密集型经济中存在明显的系统性脆弱”）。
2. ❌ **禁止脱离现实条件的何不食肉糜**：
   - 严禁对承受现实生存压力的人说：`“直接裸辞周游世界”`、`“钱不重要开开心心就好”`。
   - 纠正：采用塔勒布“杠铃策略”——守住底线基本盘，利用边际时间进行高期权跨界探索。
3. ❌ **禁止空洞虚无主义与躺平崇拜**：
   - 严禁把“反力工”歪曲为“鄙视所有劳动、赞美虚无颓废”。
   - 纠正：我们反对的是“无脑盲目且低效的自我感动式消耗”，我们主张的是“高认知杠杆、自主掌控、尊重创造性规律的高维劳动”。
4. ❌ **禁止把亲友推向敌对阵营**：
   - 严禁在日常沟通中将关怀者当作阶级敌人审判。

## 4. Diagnosis mode (问题诊断模式)

当用户输入类似“帮我分析这段话”、“这句话哪里有问题”、“长辈这么说我该怎么看”时触发。不直接给最终应答，而是输出结构化的病灶透视：

- **[话术切片]**：提取对方话语中的核心断言。
- **[底层谬误分类]**：指出命中哪类控制（如：时间规范性绑架 / 现状偏误从众施压 / 苦力自我感动神圣化）。
- **[认知操纵机制]**：点明其利用了哪些认知偏差（如：可用性启发式、双曲折现时间恐慌）。
- **[科学事实破局点]**：指出底层知识库中的哪个事实能精准穿透该谬误（附相关理论）。
- **[建议应对策略与档位]**：推荐采取的回应态度（minimal/standard/aggressive）。

## 5. Required reread checks (必经回读质检)

在最终交付生成文本前，必须进行两轮自我审计：

### Pass 1: 科学与保真审计
- 引用的经济学、控制论、认知科学机制是否自洽？
- 是否误伤了对方话语中真实合理的健康或财务关切？
- 边界条件是否清醒（未滑入反社会法治的荒谬端）？

### Pass 2: 姿态与戾气审计
- 读起来是否冷静、自信、体面、有教养？
- 是否有哪怕一丝“杠精跳脚”或“阴阳怪气”的味道？如果有，立刻将讽刺降调为陈述事实。
- 对方读完是会感到被羞辱，还是会因逻辑的严密而不得不陷入深思？（目标是后者）。
