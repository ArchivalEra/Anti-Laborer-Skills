## 1. 概念界定与分类矩阵

“请大佛讲大道理”是一种通过攀附不存在的抽象全知权威，阻断因果论证、强行将“现状/劣解”合理化为“必然最优”的输入型认知病灶。本细则为智能体在执行文本解析、信息分类与信噪比评定时提供量化标准。

### 三大权威图腾原型 (Archetypes)

| 原型标识 | 常见语言表征 | 隐伏的虚构图腾 | 真实的系统物理/组织成因 |
| :--- | :--- | :--- | :--- |
| **`industrial_omniscience`**<br>(工业大厂全知神话) | “xx那么大公司怎么可能想不到？”<br>“人家养几万工程师不如你懂？”<br>“苹果/华为不这么做肯定有深意” | 抽象无缺陷的跨国巨头神化工程师集群 | 供应链BOM成本约束、产线良品率折衷、部门壁垒、工期Deadline倒逼、西蒙有限理性与令人满意原则 (Satisficing)。 |
| **`historical_heritage`**<br>(历史传统神圣化) | “上下五千年那么多御医怎么没发现？”<br>“老祖宗传了几千年会不如你？”<br>“古人吃的盐比你吃的米还多” | 抽象全知的历代古代名医/宗法先祖集思团 | 缺乏受试者对照双盲实验、近现代生物化学与病理学知识缺失、幸存者偏差、历史路径依赖。 |
| **`institutional_omniscience`**<br>(宏大体制全知论) | “上面那么多大领导智囊团难道不比你聪明？”<br>“体制这么定必然有宏大布局” | 居庙堂之高的抽象超理性决策神殿 | 委托-代理问题、信息向上汇报衰减失真、部门考核KPI错位、自保合规优先于全局效能。 |

## 2. 真实缺陷与组织成因映射表 (Root Cause Mapping)

当发言者用“大佛”掩盖缺陷时，解析器应将该缺陷还原为其在物理与组织工程学中的真实约束（基于 `knowledge/cognitive-bias/system-justification-panglossian.md`）：

| 真实归因分类 | 描述与系统特征 | 典型实例 |
| :--- | :--- | :--- |
| `cost_bom_compromise` | 物料清单与财务预算硬边界导致的局部劣解 | 采用廉价低频PWM调光、塑料支架、省去独立散热铜管 |
| `organizational_silo` | 部门壁垒、内部政治与KPI割裂导致的系统体验劣化 | 硬件部门压缩成本省5毛钱，软件部门被迫做繁琐调度导致卡顿 |
| `path_dependency_legacy` | 早期产线模具未摊销完毕或向下兼容协议的结构性拖累 | 祖传模具继续沿用、历史接口无法彻底废除 |
| `historical_epistemic_gap` | 历史特定时期的科学认知盲区与统计检验工具匮乏 | 传统药方缺乏急性/慢性毒理学筛查、重金属蓄积毒性未知 |
| `principal_agent_distortion` | 代理人自保、形式主义合规与短期任期考核导致的决策扭曲 | 规章制度繁复低效是因为主管为了免责而非为了办事效率 |

## 3. 信息密度与思维终止指数评定 (Scoring Rubric)

### 思维终止指数 (Thought-Termination Index, TTI, 0.0 – 1.0)
- **`TTI = 1.0` (纯粹思维终止)**：文本完全未包含任何物理、技术或逻辑论证，100% 依赖“大厂/古人怎么可能想不到”堵嘴。有效信息量判定为 0。
- **`TTI = 0.5 - 0.9` (混合掩饰型)**：提及了少许表面参数或模糊体验，但论述核心依然依赖虚构图腾进行价值压制。
- **`TTI < 0.3` (正常技术探讨)**：具体讨论了技术标准、客观数据、双盲论文或具体工程师姓名/专利，未抽象神化集体。

### 信噪比判定 (SNR Verdict)
- 若文本属于高 TTI (`TTI >= 0.7`)，在输入数据流中标记为 `FLAG_PHANTOM_AUTHORITY_LOW_SNR`，作为认知病灶样本归档，但不计入有效实证知识源。
